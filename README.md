# Roast Your Own Agent

A one-line roast of my own AI agent, who turned a three-line email into a
nine-page report, a meeting, and a 40,000-token invoice for reading my own
inbox back to me.

`main.py` writes the entry line to `entry.txt` in `MAKEFUN_OUTPUT_DIR`
(default `/output`).
